# Hotword models

No hotword model is distributed with this project.

Place a model that you are licensed to redistribute or use in this directory.
Snowboy personal models use the `.pmdl` extension and universal models use
`.umdl`. The license bundled with Snowboy states that hotword models other than
the upstream `snowboy.umdl` model are governed by their own licenses.

The model must accept 16 kHz, mono, signed 16-bit PCM. Use the sensitivity and
frontend settings that match the way the model was trained.
